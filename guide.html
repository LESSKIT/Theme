Syrene is designed for multi-category, multi-brand stores. This guide explains how to configure the theme using Shopify and the theme editor. Labels can vary slightly with Shopify interface updates. The accompanying Module Reference lists every available section, its settings, blocks, defaults, and placement restrictions.

1. Install and prepare your store

  1. Open Online Store > Themes. Add Syrene from the Theme Store, or upload your authorized theme ZIP using Import theme > Upload zip file.
  2. Keep the theme unpublished while configuring it. Open Edit theme or Customize.
  3. Create your products, variants, prices, inventory, collections, menus, pages, and blog articles in Shopify.
  4. Make the products available to the Online Store sales channel. A product existing in the admin does not automatically make it available on the storefront.
  5. Configure payments, shipping, taxes, policies, and Markets in Shopify. The theme does not replace these services.

Do not unzip the theme before uploading. Do not upload the documentation ZIP as a theme.

Why do I see placeholders when my files already exist in Shopify?

Store resources and theme settings are separate. Uploaded files are available to your store, but a new theme does not know which image belongs in each banner. Product sections also need a selected collection or product. A clean theme installation does not automatically inherit another theme's saved configuration.

Select the image, collection, product, article, page, or menu in the corresponding section. Save and preview. Replace all instructional text before publishing. Demonstration images and store-specific resource selections are not included in the clean installation package.

2. Add, reuse, hide, and remove sections

Use the page selector at the top of the editor to open the appropriate template. Changes to a template affect every resource assigned to that template.

  • Add: choose Add section in the appropriate template region, select a section, and connect its resources.
  • Reorder: drag a section or block within the editor. Check the result on both desktop and mobile.
  • Duplicate: where Shopify provides Duplicate, create an independent copy. Later changes to the original do not synchronize with its copy.
  • Hide: use the visibility control. Hidden blocks still occupy section and block limits.
  • Remove: select the section or block and choose Remove. Duplicate your theme before substantial restructuring.
  • Reuse across pages: add a new instance to each eligible template and configure it separately. Resource content remains shared when both instances select the same product, collection, or page.
  • Use a different layout for selected products or pages: create an alternate template, customize it, and assign it to the intended resources in Shopify.

Global Theme settings control shared defaults. Section settings control one instance. Block settings control one repeatable item. Use Content, Layout, Style, and Behavior groups where available. An Inherit option uses the applicable shared setting.

Header and footer groups are shared across normal storefront templates. Password and gift card layouts are separate. Fixed main sections, the cart drawer, and quick look are not ordinary addable sections.

Sections included but not initially configured

Apps, Custom Liquid, Custom section, FAQ, Featured product, Content tabs, and Video are available to add even when they are absent from a default template. The Announcement bar is included in the header group but may initially be hidden. Availability depends on the section's template and region restrictions.

Blocks and limits

Use Add block inside the selected section. The editor enforces the available block types and limits. Hiding a block does not free a slot. The Footer allows three blocks in total and at most one Newsletter block. Content tabs allow up to eight tabs, and Scene shopping allows up to six product hotspots. Use the Module Reference for the current schema limits.

Custom section accepts reusable theme blocks such as Text and the Row/Column group presets. This does not mean every section accepts those theme blocks. Product and Featured product support compatible app blocks and Custom Liquid blocks. App output and subscription configuration depend on the relevant Shopify service or app.

3. Configure your brand and shared appearance

Open Theme settings to select desktop/mobile logos, favicon, Shopify font-picker fonts, colors, page width, corner styles, product-card options, cart behavior, motion, and display preferences. Use a color scheme for coordinated foreground/background colors where offered. Check contrast after changing colors, especially text over images, muted text, links, and keyboard focus.

Section spacing supports None, Compact, Comfortable, and Spacious where available. None intentionally removes that section's vertical spacing. Choose consistent levels and review neighboring backgrounds. Content width and local layout settings are independent of spacing. Long titles remain visible; use real content while choosing columns and image ratios.

4. Header, navigation, and footer

  1. Create menus in Shopify's Content > Menus area, or the equivalent navigation area in your admin.
  2. Select the main menu in Header. Add nested menu items for multi-level navigation.
  3. Configure optional secondary, right-side, or catalog menus only when using the corresponding header layout. Defaults can point to the same menu; select your intended menus to avoid repetition.
  4. Add eligible mega-menu blocks and match their menu-item field to the actual menu title. Select their collections, images, links, or pages.
  5. Preview mobile navigation, search, account access, and the shopping bag.
  6. Configure Footer menus, store text, policies, social media URLs, localization, and payment icons.

The customer-account component uses Shopify account settings. Follow on Shop and payment methods appear only when the store is eligible. Do not replace native branded payment or Shop button colors.

5. Build a useful home page

Start with navigation and category discovery, then add relevant product groups, merchandising content, and supporting information. You do not need every section on every page.

  • Banner mosaic: add tiles, upload images, choose text placement and links, and check mobile crops. Use the image focal point to keep important subjects visible.
  • Category discovery: select collections or configure the available category content. Choose a rail, guide, or directory layout as appropriate.
  • Brand discovery: add brand blocks, images, headings, and destination links. It does not create brand collections automatically.
  • Product selection: choose a collection or products, then select grid/rail presentation, columns, and card options.
  • Campaign banner: add an image, heading, text, and a destination. Use accurate campaign terms.
  • Content columns: add repeatable image/icon/text columns. Check uneven text lengths on mobile.
  • Image with text / Rich text: select the layout, upload media where needed, and add content blocks in the required order.
  • Verifiable information: provide your own accurate evidence, statistics, or testimonials. Replace example content and do not present sample figures as real business results.
  • Journal and tutorials / Buying guide: connect the articles, pages, media, or products needed by the chosen blocks. A heading alone does not associate an article.
  • Newsletter: customize the copy and connect your Shopify email-marketing workflow. Submission does not create an email campaign automatically.
  • FAQ / Content tabs: add Question or Tab blocks and write content or select pages where supported.
  • Video: choose Shopify-hosted video or a supported YouTube/Vimeo URL, then configure its cover and layout. Replace the default sample video before launch.

See the Module Reference for every section's actual fields and availability.

6. Products, cards, and quick look

Maintain titles, descriptions, media, variants, prices, inventory, unit pricing, and selling plans in Shopify. The theme displays this data; it does not invent stock or calculate a separate authoritative price.

In the Product template, add and arrange supported blocks such as Heading, Vendor, Price, Variant picker, Quantity, Buying controls, Description, Inventory status, Delivery and shipping, Pickup availability, Purchase options, Payment information, Complementary products, Rating, Share, Page popup, and Icon with text.

Connect optional pages and dynamic sources where relevant. Empty optional content may not appear. Add compatible app blocks through the editor. Test app output in the actual store.

Use product-card settings to choose the image ratio/fit, secondary images, badges, vendor, ratings, inventory, quick add, and quick look where available. Simple eligible products can use inline purchase controls. Products requiring more choices use the product page or quick-look flow. Always confirm options before purchasing.

Product media can include images, Shopify videos, supported external videos, and 3D models. Upload real media and test playback, zoom, selected-variant images, and model viewing on applicable devices.

Ratings use available review data. Missing rating data does not produce fabricated reviews. Related and complementary recommendations depend on Shopify's recommendation data and configuration; select manual fallback products where supported.

7. Inventory, delivery, pickup, and gift cards

Inventory information comes from Shopify variants. A preorder label is only a label for eligible available variants that permit continued selling; it does not create deposit or deferred-payment functionality. Configure those services separately if required.

Optional delivery information can use supported variant/product fields such as custom.delivery_information and custom.shipping_information. Define and populate them in Shopify only if you need them. Missing fields are omitted; the theme does not generate delivery estimates.

Configure local pickup in Shopify locations and fulfillment settings. The theme displays applicable availability when Shopify returns it. Tax and shipping-policy notices depend on store settings.

Gift card recipients

Enable the recipient option in the buying controls for gift card products. Customers can opt in, enter a recipient email, optional name/message, and optional send date. Email is required when opted in. The date picker allows today through the next 90 days in the customer's local timezone; leaving the date blank requests immediate delivery. Shopify processes delivery and validation.

Returned values are restored after validation and option refreshes. Correct any error before submitting. Unchecking the recipient option excludes recipient properties from the purchase.

An issued gift card displays its balance, text code, a 160px QR code, and an Apple Wallet link when available. QR generation requires JavaScript. The text redemption code remains available. The theme cannot guarantee delivery to a recipient's email inbox.

8. Build a product set and scene shopping

For Build a product set, select eligible candidate products and the minimum number of distinct products. Select a product's options and confirm them before adding the selection to the cart. Quantities must respect Shopify's minimum, increment, and maximum rules. This section adds separate Shopify cart lines; it does not automatically create bundle discounts.

If there are fewer available products than the minimum, change the candidate list or minimum. If the result of a cart request cannot be confirmed, inspect the cart before retrying to avoid duplicate additions.

For Scene shopping, upload the scene image, add product hotspots, select a product for each hotspot, and position them using the available controls. Review mobile placement. A plain image/text layout does not automatically become a hotspot layout.

For Shoppable image feed, upload images and connect products using its blocks. Social profile links are destinations; the section does not automatically import social posts.

9. Collections, search, cart, and editorial pages

Choose the Collection template to configure its banner, description, sorting, filtering layout, columns, and page size. Filters use Shopify's available filter data and Search & Discovery configuration. A filter with no applicable data may not appear.

Search supports products, articles, and pages. Predictive results depend on Shopify search data and product availability. Test meaningful search terms, no-result states, and mobile controls.

Configure cart notes, drawer/page behavior, recommendations, and accelerated checkout in Theme settings where offered. Price each is the final per-item price; Line total is the final amount for that line's quantity. Unit pricing, such as a price per 100g, is separate. Shopify's checkout determines final tax, shipping, and applicable discounts.

Create pages in Shopify and select the appropriate template. The Contact form sends store-customer inquiries through Shopify's store contact workflow; it is not the Syrene developer-support service. Use Blog and Article templates for editorial content, publication information, and comments. Enable and moderate comments in Shopify when needed.

10. Localization, preview, updates, and launch

Configure countries, currencies, and languages in Shopify Markets and language settings. Selectors appear only when relevant choices exist. Theme translations do not translate your product descriptions or articles automatically.

Preview a draft from its own theme card. Use Share preview / Copy link in the preview toolbar, and check the theme name shown there. The ordinary store domain may depend on a browser preview session. You do not need to publish to preview. Storefront access passwords and admin-account passwords are different; never send your admin password to theme support.

Before publishing, check desktop and mobile layouts, menus, all resource selections, long content, missing images, sold-out products, unavailable combinations, gift cards, recommendations, cart edits, and checkout. Verify accessibility and performance using realistic content. Do not use empty sections to judge performance.

Duplicate the theme before updating or editing code. Back up customizations and test the updated draft before publishing. Existing template assignments and store-specific settings may require review after migration. Do not overwrite new theme code with an old theme package merely to recover images.

11. Troubleshooting

  • Missing products: confirm Online Store availability, the section's product/collection selection, product eligibility, and stock state.
  • Missing images: choose the image in this theme's section; another theme's selection is not inherited automatically.
  • Missing section in Add section: check template/region restrictions and whether it is a fixed main section.
  • Cannot add another block: hidden blocks still count; review total and per-type limits.
  • No filters or recommendations: configure the corresponding Shopify data and relationships.
  • All products changed after a layout edit: they share one template; create and assign an alternate template where appropriate.
  • New template unavailable for assignment: check the templates available in the published theme and review assignments when switching themes.
  • Set cannot be added: check distinct-product minimum, availability, confirmed options, quantities, and any pending/uncertain request.
  • No subscription or accelerated payment option: check store eligibility, selling-plan setup, and section settings. Set-selection dialogs intentionally hide direct accelerated checkout.
